🖼️ Pixel Gallery — Image Gallery Website

A responsive and interactive image gallery built with HTML, CSS, and JavaScript as part of my CodeAlpha Frontend Development Internship project.

Pixel Gallery allows users to explore beautiful images across different categories, navigate through paginated results, and switch between light and dark themes.

✨ Features

🖼️ Dynamic Image Rendering — Images are rendered dynamically using JavaScript and DOM manipulation.

🗂️ Category Filtering — Filter images by Nature, Architecture, Animals, and Technology.

📄 Pagination — Browse images across multiple pages with Previous, Next, and numbered page buttons.

🌙 Light & Dark Mode — Switch between light and dark themes.

💾 Theme Persistence — The selected theme is saved using localStorage and restored when the page is revisited.

📱 Responsive Design — Layout adapts to desktop, tablet, and mobile screens.

🎨 Modern UI — Clean layout, interactive buttons, hover effects, and smooth theme transitions.

⚡ Lazy Loading — Images use the loading="lazy" attribute to help reduce unnecessary initial image loading.

🛠️ Technologies Used

HTML5 — Website structure and semantic elements.

CSS3 — Styling, CSS variables, Grid, Flexbox, transitions, and responsive media queries.

JavaScript (ES6+) — DOM manipulation, event listeners, array methods, filtering, pagination, and theme management.

Unsplash — Image sources.

🚀 Getting Started

1. Clone the repository

git clone https://github.com/hadia-malik/CodeAlpha-image-gallery-project.git

2. Navigate to the project directory

cd CodeAlpha-image-gallery-project

3. Run the project

Open index.html in your browser, or use the Live Server extension in Visual Studio Code for local development.

No additional packages or build tools are required.
